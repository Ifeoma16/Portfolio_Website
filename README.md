# Personal Portfolio Website 

A lightweight, Python-based static site generator that compiles my professional resume and project data into a website portfolio. 

Built with Python and Jinja2, this script takes a structured data dictionary (containing my skills, experience, and projects) and injects it into a custom CSS/HTML template.

## Note on Projects
The portfolio serves as a high-level showcase of my work in electrical and computer engineering. **For in-depth context, code, and demonstrations of the projects listed, please click the "View Project Details" links on the site.** These will direct you to my detailed LinkedIn posts or dedicated, project-specific GitHub repositories.
